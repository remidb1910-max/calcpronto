Methodik und Quellen

Jeder CalcPronto-Rechner wendet offizielle, datierte Regeln an. Vor jeder Veröffentlichung prüfen 195 automatische Tests die 8 Referenz-Rechenkerne, danach vergleichen 169.354 Prüfungen die Website mit diesen Rechenkernen. Letzte vollständige Prüfung: 27. November 2026.

So wird jeder Rechner geprüft

  1. Regeln aus offiziellen Texten. Jeder Satz, jede Grenze und jeder Tarif stammt aus einer datierten offiziellen Quelle: Légifrance, BOFiP, impots.gouv.fr, Urssaf, Service-Public.fr, Amtsblatt der Europäischen Union … Die Quellen jedes Rechners stehen unten auf seiner Seite und weiter unten auf dieser Seite. Ist eine Regel unsicher, lässt der Rechner sie aus seinem Umfang heraus und weist darauf hin, statt zu raten.
  2. Ein Referenz-Rechenkern, getestet an amtlichen Beispielen. Jede Berechnung wird zuerst als Referenz-Rechenkern (in Python) programmiert, mit automatischen Tests, die die von den Behörden veröffentlichten Rechenbeispiele nachrechnen: Gebührentabelle der französischen Notare, Beispiele zur französischen Einkommensteuer, Grunderwerbsteuersatz jedes französischen Départements usw. Dieselben Rechenkerne beantworten auch KI-Assistenten über den CalcPronto-Connector.
  3. Die Website mit dem Rechenkern verglichen, auf den Cent. Die Rechner dieser Website laufen in Ihrem Browser. Für jeden werden Hunderte bis Tausende Fälle vom Referenz-Rechenkern berechnet und von der Website in einem simulierten Browser erneut berechnet: Jeder Betrag wird auf den Cent verglichen, ebenso Titel, Tabellen, Links und vorausgefüllte Formulare der Seiten nach Betrag.
  4. Nichts wird veröffentlicht, wenn eine Prüfung fehlschlägt. Website und Connector werden nur veröffentlicht, wenn alle Tests und alle Prüfungen bestehen. Die Zahlen auf dieser Seite werden bei jedem Erstellen der Website automatisch aus diesen Tests erzeugt.

Aktualisierung der Sätze

Die meisten Tarife ändern sich zum 1. Januar: französisches Haushaltsgesetz (Einkommensteuertarif), Beitragsbemessungsgrenze und Mindestlohn, Mehrwertsteuersätze einiger Länder, Grunderwerbsteuersätze der französischen Départements. Andere ändern sich im Lauf des Jahres (neutraler Quellensteuersatz, ermäßigte Mehrwertsteuersätze).

Jede zu einem bestimmten Datum bekannte Änderung steht in einem Prüfkalender. Sobald die neuen Zahlen offiziell veröffentlicht sind, werden Rechenkern, Tests und Seiten aktualisiert und erneut geprüft; bis dahin wendet der Rechner die geltenden Regeln an. Hängt ein Rechner von jährlichen Tarifen ab, ist das angewandte Jahr angegeben.

Jede Woche werden zufällig ausgewählte Rechner anhand der offiziellen Quellen des Tages unabhängig von ihrem Code nachgerechnet; jede Abweichung wird sofort behoben.

Grenzen

Die Ergebnisse sind unverbindlich und ohne Gewähr. Jeder Rechner nennt unten auf seiner Seite seinen Umfang (nicht abgedeckte Fälle, Annahmen). Sie ersetzen keine fachliche Beratung und keine behördlichen Entscheidungen.

Fehler melden

Ein Ergebnis scheint falsch oder ein Satz veraltet? Schreiben Sie an remidb@outlook.fr und nennen Sie die Seite und die eingegebenen Beträge: Jede Meldung wird anhand der offiziellen Quellen geprüft.
